# Ansuman.dev  

**Live Portfolio** → [https://ansuman-mahapatra.github.io/Ansuman.dev/](https://ansuman-mahapatra.github.io/Ansuman.dev/)

A modern, fast, and fully responsive personal portfolio showcasing my journey as a **Backend Developer & AI Integration Engineer**.

### Features
- Stunning dark cyberpunk theme with neon accents + light mode toggle
- 5-second cinematic "dark side" loader with glowing particles and name reveal
- Smooth animations & hover effects
- Categorized projects (Java Desktop • Java Backend • Full-Stack & AI)
- Tech tags, gradient titles, and glass-morphism cards
- 100% mobile-responsive
- Built with pure HTML, CSS (Flexbox/Grid), and vanilla JavaScript

### Tech Stack
- HTML5 • CSS3 • Vanilla JavaScript
- Google Fonts (Inter)
- No frameworks – lightweight & blazing fast
